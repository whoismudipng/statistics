# Statistics Quiz

A small, dependency-free multiple-choice quiz covering introductory statistics:

- q1: Introduction to statistics
- q2: Graphs and frequency distributions
- q3: Descriptive measures

## Run locally

Open `index.html` in a browser. No build step or server is required.

## Host on GitHub Pages

1. Push these files to a repository.
2. In the repository, go to Settings > Pages.
3. Under "Build and deployment", choose "Deploy from a branch", select `main` and `/ (root)`, then save.
4. The quiz will be live at `https://<your-username>.github.io/<repo-name>/`.

## Files

- `index.html`: the quiz app
- `questions.js`: all questions and answer keys
- `img/`: figures used by some questions

Note: the q3 answer key was worked out separately; check it against your course material.
